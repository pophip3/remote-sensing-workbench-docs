# GeoMaskLab documentation website

English documentation for a remote-sensing segmentation and regional-analysis
workbench. **GeoMaskLab** is the current working name; a public software release
and formal open-source license remain pending.

This repository publishes documentation only. The research source is maintained
separately at [pophip3/geoscope-softwarex](https://github.com/pophip3/geoscope-softwarex),
which is currently private. The original competition repository is unchanged.

[![Documentation website](https://github.com/pophip3/remote-sensing-workbench-docs/actions/workflows/pages.yml/badge.svg)](https://github.com/pophip3/remote-sensing-workbench-docs/actions/workflows/pages.yml)

## Website contents

`site/index.html` describes the software's purpose, local startup, examples,
segmentation workflow, statistical definitions, offline evidence review,
external model configuration, reproduction checks and development limitations.
It contains no model weights, credentials, raw evaluation imagery or manuscript.

The GitHub Pages workflow publishes only the `site` directory. The live URL is
recorded by the successful deployment. Documentation is a development preview,
not a SoftwareX publication or an approved open-source software release.
